# DentalHarmonie · Neue Praxis-Website

**Was Sie bekommen — auf einer Seite.**

---

## Die Idee

Eine Website, die in den ersten drei Sekunden klar macht, dass Ihre Praxis anders ist. Kein Stock-Foto, kein Buzzword-Bingo, keine Standard-Praxis-Vorlage. Stattdessen Ihre Stimme, Ihr Portrait, Ihr Versprechen: *„Erst zuhören. Dann behandeln."*

## Was Patienten sehen

- Eine ruhige, redaktionell aufgebaute Startseite, die wie ein Magazin-Cover wirkt
- Klare Antworten auf die häufigsten Fragen (Erstgespräch, Kosten, Notfall, Kinder, Angst)
- Sprechzeiten, die automatisch zeigen *„Heute geöffnet"* am richtigen Tag
- Drei Wege zur Praxis (U-Bahn, Bus, Auto) mit Live-Karten-Links
- Ein Termin-Anfrage-Formular, das wirklich funktioniert

## Was Sie selbst können

Ein eingebautes Admin-Dashboard, mit dem Sie ohne Code-Kenntnisse:

- Texte ändern
- Sprechzeiten und Sonderzeiten pflegen
- Status setzen (Geöffnet / Urlaub / Sonderöffnung)
- Terminanfragen einsehen und exportieren
- Fotos austauschen

Eine 45-Minuten-Einweisung zeigt Ihnen, wie das geht. Danach sind Sie unabhängig.

## Was technisch dahinter steckt

- Eigene Datenbank für Terminanfragen — keine Mail-Provider, keine Drittanbieter-Lock-In
- DSGVO-konform — keine Tracker, kein Cookie-Spam
- Optimiert für Google (strukturierte Daten nach Schema.org)
- Lädt schnell, auch auf alten Handys
- Funktioniert auf Smartphone, Tablet, Desktop *und* gedruckt als saubere PDF
